## <a id="math">数学・科学</a>

[Wolfram MathWorld](http://mathworld.wolfram.com/)
: (英語) おそらく、世界で最も数学の情報の充実しているサイト。 数学辞書です。

[KAWAMURA AKIRA'S CYBER WORLD](http://home.p07.itscom.net/strmdrf/index.htm)
: 電磁気学、相対性理論を中心として、数理科学を解説しているサイト。 内容は少し難しいですが、量的に充実しています。

[ときわ台学](http://www.f-denshi.com/)
: 理系研究者＆学生お助けサイト。 応用数学に関する教科書的解説が載っています。

[『数学者の密室』](http://www.asahi-net.or.jp/~KC2H-MSM/mathland.htm)
: 整数論の未解決問題への挑戦。

[はまぐりの数学](http://www.rd.mmtr.or.jp/~bunryu/index.htm)
: 数学雑記。 数学に興味を持ってもらうべく、 「数学は自然、社会、文学と、どうつながっているかという話」をいろいろと書いています。

[Weekend Mathematics](http://www.junko-k.com/index.html)
: 数学の記事いろいろ。 毎月1問、数学の問題が出題されています。

物理のかぎしっぽ http://www12.plala.or.jp/ksp/index.html （リンク切れ）
: 物理学と数学とコンピュータの勉強ノートです。

数学講座 http://s-akademeia.sakura.ne.jp/main/math_lecture.htm（リンク切れ）
: 高校以下から大学教養以上のレベルまで多彩な数学記事がそろっています。

良質な教科書系ウェブサイト集 http://kanou.jp/archives/001064.php （リンク切れ）
: 良質なサイトへのリンク集。

[TeX Documents of Gen KUROKI](http://www.math.tohoku.ac.jp/~kuroki/TeX/index-j.html)
: 主に数学に関する講演や講義資料を公開しています。

数学科の職員室から http://www12.ocn.ne.jp/~puzzle/syokuinnsitsu.htm （リンク切れ）
: 高校の数学教員の方が数学とかの話を書いているページ。

[アトムの物理ノート](http://letsphysics.blog17.fc2.com/)
: 物理や数学の話題中心のブログ。

[津嶋風のアレ](http://tsushima.homeip.net/top.html)
: 量子論などの自然科学に関する記事を公開しています。

## <a id="d0e75">プログラミング一般</a>

[@IT (アットマーク・アイティ)](http://www.atmarkit.co.jp/index.html)
: ITにかかわる話題全般を扱ったサイト。C#入門の連載などもあります。

[CodeZine [コードジン]](http://codezine.jp/)
: ソースコードを中心に、現場の開発者が実装上の問題を解決するためのアイデア、ノウハウ、テクニック、ハウツー、チュートリアル、その他関連情報を幅広く公開しています。

[Cプログラミング診断室](http://www.pro.or.jp/~fuji/mybooks/cdiag/index.html)
: 副題「うつくしく健康なプログラムのために」。プログラマならここは一度は見に行くべし(義務です)。

[Cygwin](http://www.cygwin.com/)
: Cygwin は UNIX の gcc などを中心としたツール・開発環境をそのまま Windows に移植したものです。

[CodeGuru](http://codeguru.earthweb.com/)
: (英語) C# ＆ .NET、VC++、VBを中心にWindowsプログラミングに関する記事があります。

[オブジェクト指向の広場](http://www.tech-arts.co.jp/oo/oo.html)
: オブジェクト指向言語やUMLなど、オブジェクト指向に関する情報を公開しています。

[PEACE CODE](http://www.aya.or.jp/%7Esanami/peace/index.html)
: コード最適化の話。

[Hello World](http://www.latech.edu/~acm/HelloWorld.shtml)
: (英語) ただひたすらHello Worldプログラムばかりを集めたサイト。さまざまなプログラミング言語でHello Worldを作成しています。

## <a id="algo">アルゴリズム</a>

[Algorithm Collection](http://alfin.mine.utsunomiya-u.ac.jp/~niy/algo/)
: 暦のアルゴリズムや(曜日・和暦の算出、閏年の判定)、ソート、文字列検索、探索、符号化アルゴリズム、文字コード変換、基数変換、素数判定、多倍長整数 等。

[TOKUTEI: algorithm](http://www-or.amp.i.kyoto-u.ac.jp/algo-eng/)
: 幾何アルゴリズム中心。

[数学・アルゴリズム研究室](http://www.sm.rim.or.jp/~shishido/cpro.html)
: 素因数分解や微分方程式の数値解法などの数学アルゴリズム。

[井澤裕司](http://laputa.cs.shinshu-u.ac.jp/~yizawa/)
: 論理回路・ディジタル信号処理などに関する教科書的な記事を公開していらっしゃる方のサイト。

## <a id="latex">LaTeX</a>

LaTeXしよう！ http://www.topstudio.co.jp/~kmuto/latex/ （リンク切れ）
: LaTeXの解説ページ(日本語)。

[LaTeX help](http://www.emerson.emory.edu/services/latex/latex_toc.html)
: LaTeXのリファレンスページ(英語)。 全文検索付きなので便利。

[奥村晴彦のホームページ ](http://oku.edu.mie-u.ac.jp/~okumura/)
: 「LaTeX2ε美文書作成入門」の作者 奥村晴彦氏のウェブページ。 「LaTeX2ε美文書作成入門」のサポートページや日本語TeXに関する情報があります。

## <a id="dictionary">辞書</a>

[英辞郎 on the Web](http://www.alc.co.jp/)
: 英和/和英、単語辞書。他、英語表現辞典・語源辞典・ビジネス英語辞書などあり。

[goo 辞典](http://dictionary.goo.ne.jp/index.html)
: 英和/和英、単語辞書。他、国語辞典・新語辞典あり。

[エキサイト翻訳](http://www.excite.co.jp/world/)
: 英和/和英、全文翻訳。他、URLを指定してウェブページを全文翻訳するサービスあり。

[AltaVista - World/Translate](http://babelfish.altavista.com/translate.dyn)
: 英和/和英、全文翻訳。他、フランス語・ドイツ語・スペイン語、ポルトガル語、イタリア語に対応。

[Dictionary.com](http://dictionary.reference.com/)
: 英英辞書 ＆ 英語同義語辞書。
