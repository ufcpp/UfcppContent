## <a id="sec-generated-title-2"></a> <a id="csharp"></a>C

[MSDN Online .Net Developer Center](http://www.microsoft.com/japan/msdn/netframework/)
: マイクロソフトの.Netフレームワーク公式ホームページ。.Netフレームワークはここからダウンロードすることができます。

[SharpDevelop](http://icsharpcode.net/OpenSource/SD/default.asp)
: オープンソースなC#統合開発環境。 ソース付きです。

[C# Programming](http://uchukamen.com/)
: C# 初心者のためのヒント、チップス等が載っています。

[翔ソフトウェア](http://www.shos.info/)
: C/C++/C# による開発や、オブジェクト指向技術、そして XP 関連を中心に、 ソフトウェア開発のための技術情報をご紹介しています。

[WisdomSoft](http://wisdom.sakura.ne.jp/)
: 非常に多彩な言語・API に関する入門記事が揃っています。

[WoodenSoldier Software](http://www.woodensoldier.info/)
: C# に関する TIPS を非常に多く取り揃えています。

[C# と VB.NET の入門サイト](http://jeanne.wankuma.com/)
: 名前どおり、C# と VB.NET の入門サイトです。 サンプルが充実しています。

[AILight](http://www.ailight.jp/)
: C# や .NET Framework に関して、いろいろ研究していらっしゃいます。

[独学C#](http://www12.plala.or.jp/dokugaku/)
: C# の入門講座、リファレンスや、 C# で作成したフリーウェアのソースを公開しています。

[C#Note](http://www.geocities.jp/takamori700/index.htm)
: 趣味でMicrosoft Visual C# .NETを勉強している人のためのC#入門サイトです。

[.NET のつぼ](http://park16.wakwak.com/~mimi/dotnet/)
: C#, VB.NET による .NET プログラミングの逆引きマニュアルです。

[C#を攻略しよう](http://www.kisoplus.com/)
: Visual C# をサンプルプログラムを交えながら解説しているサイト。
