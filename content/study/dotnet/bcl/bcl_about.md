# 基本クラスライブラリ

## <a id="sec-generated-title-1"></a> <a id="abst"></a>概要

.NET Framework の標準ライブラリの中でも、基本中の基本の部分。
BCL（Basic Class Library）


## <a id="sec-generated-title-2"></a> <a id="plan"></a>追記予定

どこまでが BCL だろ（調べる）。
ECMA 標準化されてる部分？

System.Windows（WPF 用）とか System.Web（ASP.NET 用）とか除いた部分。
共通部分。

ついでなので、Portable Class Library を紹介。
デスクトップ版 .NET Framework だけじゃなくて、Silverlight（ブラウザー版、Windows Phone 7 版）でも共通で使える部分。

* レガシー削除

* セキュリティ的に怪しいもの削除

* 時間がかかる処理は非同期版のみ
