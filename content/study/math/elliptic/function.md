# 楕円関数

## <a id="sec-generated-title-1"></a> <a id="abstract"></a>概要

1価解析的で2重周期を持つ関数のことを<strong id="d77e8" class="keyword">楕円関数</strong>（elliptic function）と呼びます。


## <a id="sec-generated-title-2"></a> <a id="plan"></a>執筆予定

```text
1価解析関数の周期性
  - 周期を持たない
  - 1つの周期(T)を持つ
  - 2つの周期(T1, T2)を持つ
    (ただし、T1, T2 は T1 ≠ k T2 (∃k∈R) となるような複素数)
  のいずれかになる。

2つの周期を持つ関数を2重周期関数（doubly periodic function）と呼ぶ。

1価解析2重周期関数は楕円積分の逆関数として表すことが出来る。

そこで、1価解析2重周期関数を楕円関数と呼ぶ。
```
