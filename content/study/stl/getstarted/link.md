# リンク集（C/C++）

## <a id="sec-generated-title-1"></a> <a id="cpp"></a>C++ 一般

[Bjarne Stroustrup's Homepage](http://www.research.att.com/~bs/homepage.html)
: (英語) C++はこの人が設計しました。

[C++ Codeing Standard](http://www.possibility.com/Cpp/CppCodingStandard.html)
: (英語) C++のソースコードの書き方(インデントの仕方、変数名のつけ方など)に関する提案をしているページ。すべてがすべて同意できるわけではありませんが、参考になります。(英語)



## <a id="sec-generated-title-2"></a> <a id="stl"></a>STL

[STLのページ(角 正史のページ)](http://www.wakhok.ac.jp/~sumi/stl/)
: STLについて解説しているページ。



## <a id="sec-generated-title-3"></a> <a id="lib"></a>ライブラリ

[Boost C++ Libraries](http://www.boost.org/)
: (英語) C++のライブラリ集。 標準ライブラリに足りていない多くの機能を提供しています。 Boost ライブラリの中から標準ライブラリに採用されたコードも多数ですし、 Boost そのものを標準ライブラリに取り込む活動も行われています。

[Loki](http://sourceforge.net/projects/loki-lib/)
: (英語) C++ のテンプレート機能を使って、 デザインパターン開発を支援するライブラリ。 C++ テンプレートが以下に強力か（また、同時に、以下に複雑で凶悪か）が分かるライブラリ。 Modern C++ Design （訳書：ISBN:4894714353）という書籍で詳しく解説されています。
